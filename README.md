

Users can create characters, build campaigns, assign characters to campaigns, track sessions and loot, manage miniature painting projects, share builds, and eventually interact with an activity feed and marketplace workflows.


# Kobold Market

Kobold Market is a hybrid Dungeons and Dragons campaign manager, miniature showcase, activity tracker, and hobby organizer.

## Tech Stack
- ASP.NET Core
- EF Core
- SQL Server (localDb in dev)
- React
- JavaScript

## Project Structure
- src/backend
- src/frontend

## Running the backend
1. Go to src/backend/KoboldMarket.Api
2. Run dotnet run

## Running the frontend
1. Go to src/frontend/kobold-market-web
2. Run npm install
3. Run npm run dev
